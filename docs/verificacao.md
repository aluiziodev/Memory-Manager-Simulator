Os builds limpos com e sem Qt foram compilados com `-Wall -Wextra -Wpedantic`, sem avisos de compilação. CTest passou com 20/20 testes no build Qt e 11/11 no build sem Qt. A referência por byte comparou 8 sementes de 2000 operações, totalizando 16 mil passos. A CLI e o executável visual iniciaram no Windows sem ajuste manual de `PATH` após a cópia das DLLs pelo build.

A especificação apresenta `free_id`, `free_addr`, `show` e `stats` como nomes de métodos. A API interna adotou `freeId`, `freeAddr` e `getStats`; `show` é formatado na CLI, conforme o contrato registrado no plano. O comportamento pedido está implementado, mas uma correção que exija literalmente essas assinaturas deve ser confirmada com o professor.

O workflow Linux está configurado, mas não havia um ambiente Linux acessível nesta máquina para executá-lo localmente. Seu resultado deve ser conferido após o envio das alterações ao repositório.
